# ASD-STE100 Word Choices

This reference provides approved replacements for common unapproved words
and phrases under the ASD-STE100 standard. It does not replace the official
specification. Request the specification at no cost from <https://asd-ste100.org>.

If a word does not appear in this file, check the word against the official
Dictionary.

## Words With One Approved Meaning

STE restricts each approved word to one meaning. Do not use an approved word
for another sense:

<!-- ste-lint-disable -->
| Word | Approved meaning | Do not use for |
|---|---|---|
| `about` | approximately | on the subject of |
| `clear` | to remove an obstruction | easy to understand |
| `close` | to shut | near |
| `fit` | to install a part | correct size |
| `follow` | to come after | to obey |
| `free` | to release | at no cost |
| `like` | the same as | to want |
| `only` | no more than | alone |
| `right` | opposite of left | correct |
| `test` | noun (`do a test`) | verb (`test the component`) |
<!-- ste-lint-enable -->
