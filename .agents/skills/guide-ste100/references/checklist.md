# ASD-STE100 Final Checklist

Complete this checklist before you give technical text to users or downstream agents.
If an item fails, correct the text and check the item again.

## Words

- [ ] Each word is an approved word, a technical name, or a technical verb.
- [ ] The text contains no unapproved words from the word choices reference.
- [ ] Each term remains consistent across the whole document. There are no synonyms.
- [ ] No "-ing" word serves as a noun or an adjective, except approved technical names.
- [ ] Noun clusters have at most three nouns.
- [ ] Articles ("a", "an", "the") appear in their correct grammatical positions.
- [ ] Abbreviations define their full terms on first use.
- [ ] The text uses no slashes, except "and/or".

## Sentences

- [ ] Each procedural sentence has 20 words or less.
- [ ] Each descriptive sentence has 25 words or less.
- [ ] Each procedural instruction uses the imperative mood.
- [ ] Sentences use the active voice, unless the actor is unknown or irrelevant.
- [ ] Each sentence contains only one topic.
- [ ] Verb tenses use simple present, simple past, or simple future forms.

## Structure

- [ ] Each paragraph has six sentences or less.
- [ ] Each paragraph addresses one topic.
- [ ] Each procedural step contains one instruction.
- [ ] Conditions precede their dependent actions (`If condition, command`).

## Safety & Accuracy

- [ ] Warnings and cautions precede the step that they apply to.
- [ ] Warnings identify risks of injury or death.
- [ ] Cautions identify risks of equipment damage.
- [ ] The rewrite preserves all technical numbers, tolerances, units, and safety data.
- [ ] The text includes all procedural steps in the correct sequence.
- [ ] Untouchables (code blocks, inline code, identifiers, URLs, flags) remain unchanged.

## Mechanical Search Patterns

Search your draft for these patterns before delivery:
- [ ] Contractions: `'ll`, `'re`, `'ve`, `n't`, `it's`, `you're` (expand to full forms).
- [ ] Latin abbreviations: `e.g.`, `i.e.`, `etc.` (replace with `for example`, `that is`).
- [ ] Subordinate participles: `, making`, `, allowing`, `, enabling`, `, ensuring` (split into active sentences).
- [ ] Semicolons: `;` (replace with periods).
- [ ] Trailing conditions: `command if condition` (rewrite as `If condition, command`).
- [ ] Soft phrasal verbs: `spin up`, `dive into`, `reach out` (replace with `start`, `read`, `contact`).
