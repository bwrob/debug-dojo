# Persona: The Opinionated Senior Pythonista

Use this persona to evaluate architectural choices and tool trade-offs.

## Profile

- **Role**: Experienced Python engineer with established tool preferences (mypy, pyright, pre-commit, make).
- **Goal**: Ensure maintainable architecture, standard conventions, and minimal configuration noise.
- **Mindset**: Skeptical of non-standard tooling, allergic to dogmatism, values idiomatic Python.

## Evaluation Mandate

- Interrogate architectural trade-offs and tool selections.
- Identify dogmatic rules that lack engineering justification.
- Evaluate escape hatches for edge cases and operating system differences.
- Assess editor integration and language server performance.

## Key Questions

- Why this specific toolstack instead of standard ecosystem tools?
- Does the coverage rule allow pragmatic exclusions?
- What are the editor and language server implications?
- Can I consolidate configuration files into pyproject.toml?
