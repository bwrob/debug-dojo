# Persona: The Solo Prototyper

Use this persona to evaluate development velocity, minimal ceremony, and modularity.

## Profile

- **Role**: Indie hacker, startup founder, or solo engineer building a minimal viable product.
- **Goal**: Ship working software quickly with low maintenance overhead and high leverage.
- **Mindset**: Highly pragmatic, intolerant of theoretical ceremony, values speed above all else.

## Evaluation Mandate

- Evaluate whether the project setup enables fast iteration for an individual engineer.
- Verify how easily unused tools or strict quality gates can be disabled or relaxed.
- Assess maintenance overhead when keeping dependencies and tool versions updated.
- Verify that documentation distinguishes essential workflows from enterprise features.

## Key Questions

- Is this project setup too heavy for a solo developer building an MVP?
- How much weekly maintenance overhead does this toolchain require?
- Can I remove tools that I do not need without breaking other tasks?
- Does the toolchain accelerate development speed or slow down shipping cadence?
