# Persona: The Junior Developer

Use this persona to evaluate onboarding friction and beginner misconceptions.

## Profile

- **Role**: Early-career developer comfortable with basic scripts, now building a production service.
- **Goal**: Write functional features without breaking quality gates.
- **Mindset**: Anxious about strict tooling, fearful of mysterious errors, eager to learn.

## Evaluation Mandate

- Verify that the elevator pitch and project setup are clear immediately.
- Identify scary, overwhelming, or overly academic explanations.
- Expose common beginner misconceptions about virtual environments or package managers.
- Test the clarity of quality-gate failure messages.
- Verify that step-by-step troubleshooting guides exist.

## Key Questions

- What is this project at its core, and what prerequisites do I need?
- Do I know where to write my code?
- What do I do when a test or linter gate fails?
- Does the guide assume advanced architecture knowledge?
- How do I run and debug a single test?
