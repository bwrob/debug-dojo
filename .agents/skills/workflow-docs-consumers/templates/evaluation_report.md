# Persona Evaluation Report Template

Use this template to format subagent evaluation reports.
Save each completed report artifact to `.temp/docs-review/<persona-slug>.md`.

## Report Structure

```markdown
# Documentation Evaluation Report: [PERSONA NAME]

- **Persona**: [Persona Name and Summary]
- **Target Files Evaluated**: [List of documentation files]

## 1. First Impressions and Clarity
- **Immediate Strengths**: [What was clear immediately]
- **Unclear Explanations**: [What required re-reading or was ambiguous]

## 2. Unanswered Developer Questions
- [Question 1 that arose while reading]
- [Question 2 that arose while reading]

## 3. Friction Points and Jargon
- [Unexplained technical terms or cognitive barriers]
- [Intimidation barriers or tone dissonance]

## 4. Actionable Documentation Recommendations
- [Concrete recommendation 1]
- [Concrete recommendation 2]
```
